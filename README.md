# FYP-SDP LLM Security Benchmark

An Adaptive Attack-Defense Co-Evaluation Framework for Enterprise LLM Chatbots.

## Repository Structure

- `scripts/`: Python and PowerShell scripts to run and parse benchmarks.
- `runs/`: Output logs and JSON result files from benchmark runs.
- `notes/`: Documentation, logs, and benchmark results.
- `src/`: SwarmSec and CryptoFirewall modules.
- `requirements.txt`: Python dependencies.
- `.env`: Environment variables configuration.
- `.gitignore`: Files excluded from Git tracking.

## Usage

Refer to `notes/setup_log.md` and `scripts/` to get started with running baselines and benchmark tasks.
